# BusGuard Agent · 智能母线健康智能体

镇江辉虹电气智能母线运维工作台原型。项目把母线的温度、电气量、拓扑、告警、趋势诊断和现场工单收敛到一套可定位、可审计的交互系统。

## 页面结构

- 数字孪生总览：按楼层、回路、相别定位母线与测点
- 节点监测：温度、电流、电压、健康分、趋势与 AI 诊断链
- 母排导体：A / B / C / N / PE 分相结构与热力分布
- 运维闭环：告警 → 工单 → 处置 → 复测 → 关闭
- 健康分析：趋势、负载、温升与历史事件综合评分
- 智能体引擎：自然语言查询风险、原因和维护建议
- 市场对标：对照 Siemens、Schneider、Eaton 与国内常见方案
